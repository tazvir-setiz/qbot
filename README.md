# ربات برنامهٔ مطالعهٔ قرآن

اجرای پروژه با Python 3.11 یا جدیدتر (از جمله 3.14):

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe b.py
```

فایل `.env` موجود حاوی تنظیمات قبلی پروژه است. برای نصب جدید، `.env.example` را به `.env` کپی کنید و مقدارها را پر کنید. فایل واقعی `.env` را منتشر نکنید.

| متغیر | کاربرد |
| --- | --- |
| BOT_TOKEN | توکن BotFather |
| GROUP_ID | شناسهٔ منفی گروه مقصد؛ بات باید اجازهٔ ارسال داشته باشد |
| ADMIN_PASSWORD | رمز ورود مدیریت |
| ADMIN_USER_IDS | اختیاری: شناسهٔ عددی مدیران با کاما؛ این افراد نیز رمز را وارد می‌کنند |
| TIMEZONE | پیش‌فرض Asia/Tehran |
| DB_PATH | مسیر دیتابیس نسبت به پوشهٔ پروژه |
| SURAH_LIST_FILE | مسیر فهرست سوره‌ها نسبت به پوشهٔ پروژه |
| LOG_LEVEL | سطح لاگ: INFO، WARNING، ERROR یا DEBUG |

متغیرهای محیط سیستم بر `.env` اولویت دارند. فرمت فایل `KEY=value` است؛ کامنت باید در خط جداگانه باشد. کوتیشن اختیاری است؛ جایگذاری متغیرها و مقدارهای چندخطی پشتیبانی نمی‌شود.

## استفاده

در گفت‌وگوی خصوصی `/start` را بزنید و رمز را وارد کنید. سوره یا صفحه، دورهٔ مثبت و ساعت اولین ارسال را تنظیم کنید؛ سپس «شروع / ادامه ارسال» را بزنید. اولین ارسال در نزدیک‌ترین زمان ساعت انتخاب‌شده انجام می‌شود و ارسال‌های بعدی طبق فاصلهٔ تعیین‌شده هستند. تغییر ساعت، دوره یا سوره در یک برنامهٔ فعال، زمان اولین ارسال آن را دوباره تعیین می‌کند. تغییر تنظیمات برنامهٔ متوقف، آن را خودکار فعال نمی‌کند.

`/cancel` ورودی فعلی را لغو می‌کند. خروج، دسترسی مدیریت را می‌بندد؛ برای توقف پیام‌های گروه از دکمهٔ توقف استفاده کنید. پس از ری‌استارت دوباره رمز لازم است؛ برنامه‌های فعال ادامه می‌یابند. بعد از پنج رمز اشتباه، ورود پنج دقیقه محدود می‌شود. فقط یک نمونهٔ بات با یک توکن اجرا کنید.

## ساختار

- `main.py`: نقطهٔ اجرا
- `quran_bot/config.py`: تنظیمات و خواندن `.env`
- `quran_bot/database.py`: ذخیره‌سازی و مهاجرت افزایشی دیتابیس قبلی
- `quran_bot/catalog.py`: خواندن و اعتبارسنجی فهرست
- `quran_bot/formatting.py`: تاریخ شمسی و متن پیام
- `quran_bot/scheduling.py`: ارسال و زمان‌بندی پایدار
- `quran_bot/handlers.py` و `menus.py`: تعامل و دسترسی مدیریت
- `quran_bot/application.py`: چرخهٔ راه‌اندازی و توقف

ترتیب سوره‌ها همان ترتیب `surah_list.txt` است، نه ترتیب صفحات؛ این ترتیب برای سازگاری با شناسه‌های دیتابیس قبلی حفظ شده است. هنگام استفاده از دیتابیس قبلی، ترتیب فایل را تغییر ندهید. صفحهٔ مشترک میان دو سوره برای هر سوره جداگانه ارسال می‌شود. هر مدیر برنامهٔ مستقل دارد و همه به `GROUP_ID` ارسال می‌کنند.

زمان ارسال بعدی ذخیره می‌شود. بعد از قطعی، حداکثر یک پیام عقب‌افتاده ارسال می‌شود؛ پیام‌ها به‌صورت انبوه جبران نمی‌شوند. خطای موقت شبکه موجب تلاش دوباره بدون جلو رفتن صفحه می‌شود. حذف دسترسی گروه، برنامه را متوقف می‌کند. به‌دلیل جدا بودن تراکنش تلگرام و SQLite، اگر پردازش دقیقاً پس از ارسال و قبل از ثبت دیتابیس قطع شود، یا پاسخ ارسال در شبکه گم شود، امکان تکرار همان پیام وجود دارد.

## رابط تلگرام

پنل اصلی وضعیت، صفحهٔ بعدی، پیشرفت سوره و زمان ارسال بعدی را با تاریخ شمسی نشان می‌دهد. منوهای دکمه‌ای همان پیام را ویرایش می‌کنند؛ پاسخ به ورودی متنی پنل جدیدی می‌سازد. `/menu` و `/status` پنل را باز می‌کنند و `/help` راهنما را نشان می‌دهد. فهرست دستورات و دکمهٔ Menu در اجرای بعدی بات ثبت می‌شوند.

انتخاب سوره به‌صورت دو‌ستونه و صفحه‌بندی‌شده است. ترتیب نمایشی بر اساس صفحات قرآن است و ترتیب ذخیره‌شدهٔ برنامه تغییر نمی‌کند. جست‌وجوی بخشی از نام، دوره‌های آماده و ساعت‌های پیشنهادی نیز در دسترس هستند.

از [امکانات Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton) شامل دکمه‌های رنگی (`style`)، کپی متن (`CopyTextButton`) و راهنمای جمع‌شونده استفاده شده است. رنگ‌ها با `api_kwargs` در نسخهٔ فعلی کتابخانه ارسال می‌شوند. نمایش رنگ و امکانات جدید به نسخهٔ اپ تلگرام کاربر بستگی دارد. دکمهٔ کپی فقط برای متن‌های حداکثر ۲۵۶ کاراکتری نمایش داده می‌شود.

پیش‌نمایش فقط داخل پنل است و صفحه را جلو نمی‌برد. پیام دلخواه پس از تأیید یک‌بارمصرف ارسال می‌شود؛ تأیید پس از ۱۰ دقیقه، لغو یا جابه‌جایی منو منقضی می‌شود. در صورت خطای مبهم شبکه، قبل از ارسال مجدد گروه را بررسی کنید. آلبوم پشتیبانی نمی‌شود؛ رسانه‌ها را تکی بفرستید.

## تست محلی

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست‌ها از دیتابیس موقت و بات ساختگی استفاده می‌کنند؛ به تلگرام پیام نمی‌فرستند و دیتابیس اصلی را تغییر نمی‌دهند.
